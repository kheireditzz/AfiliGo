# AffiliateGo - Platform AI Konten Affiliate & Storyboard 8K

Platform generator naskah affiliate, visual AI storyboard realistis, dan multi-server AI generation hub.

## 🚀 Fitur Utama
- **AI Storyboard & Foto 8K**: Generator skrip viral, hook, scene shot, narasi voiceover, dan prompt Flux 8K.
- **Vision AI Auto-Analyzer**: Analisa foto produk, model & latar belakang otomatis menggunakan Google Gemini Pro.
- **Multi-Server Hub (Server Generate)**: Pilihan terintegrasi Google Labs Flow AI, Google AI Studio Pro, dan Flux 8K.
- **Sistem Langganan VIP & QRIS Dongtube (Rp 25.000)**: Akses 30 hari dengan countdown timer otomatis.
- **Database Terintegrasi**: Supabase PostgreSQL & Cloud Storage.

## 📦 Deployment ke Vercel

1. Buka [Vercel Dashboard](https://vercel.com/new).
2. Import repository GitHub **AffiliateGo**.
3. Masukkan Environment Variables:
   - `SUPABASE_URL`: `https://bvmmshskoqylzptoyuxf.supabase.co`
   - `SUPABASE_ANON_KEY`: `<anon_key>`
   - `SUPABASE_SERVICE_ROLE`: `<service_role>`
   - `GEMINI_API_KEY`: `YOUR_GEMINI_API_KEY`
4. Klik **Deploy**.

## 🗄️ Setup Database Supabase
Buka **SQL Editor** di Dashboard Supabase (`https://supabase.com/dashboard/project/bvmmshskoqylzptoyuxf/sql/new`) dan jalankan skrip `supabase_schema.sql`.
